# Изменения

## 0.3.4

- Жанры сгруппированы по родительским направлениям: рок, поп, фолк, метал, электроника и другие.
- На мобильном экране кнопки «Волна по треку» и «Волна по жанру» показывают текст под регулятором громкости.

## 0.3.3

- «Моя волна» переведена на Rotor Session API: `radio_session_id`, session queue, session feedback и продолжение без возврата к первому пакету.
- Добавлен каталог станций из API: волны по настроению, занятию, жанру, эпохе, языку и региону.
- Добавлены seeds текущего трека: волна по треку и волна по жанру.
- Технические seed-имена скрыты; станции сгруппированы в компактные горизонтальные ряды.
- Кнопки «Волна по треку» и «Волна по жанру» перенесены под регулятор громкости.
- Резервные копии установщика вынесены из `custom_components`, чтобы HA не сканировал их как интеграции.

## 0.3.2

- Волна под управлением HA по схеме Lampa: продолжение через Rotor cursor, batch и feedback; отдельная очередь каждой колонки.
- Настроения из API и волна по текущему треку. Продолжение работает без открытой страницы, пока работает HA.
- Выбор колонки одним тапом: обновления HA сохраняют кнопки и не переставляют нажатую карточку.
- Длинный ползунок громкости без повторения имени станции, увеличенный бегунок.
- На телефоне: сведения о треке, затем все кнопки управления со «Стоп», затем прогресс, громкость и дополнительные действия.

## 0.3.1

- Исправлена ошибка главной и «Мне нравится» для аккаунта с пустой коллекцией треков.
- Высота панели заполняет оставшееся окно даже при контейнере HA без заданной высоты.
- Отдельный раздел «Аудиокниги»: книги из коллекции и каталога, поиск по книгам, главы и загрузка следующих страниц.
- Обзор всех 163 методов библиотеки и результатов чтения API в `docs/api-capabilities.md`.

## 0.3.0

- Отдельная страница глобального поиска; фильтрация внутри разделов.
- Крупная кнопка выбора нативного `source` колонки, включая настроенные внешние плееры.
- Общая прокрутка рабочей области колесом мыши с закреплённым плеером.
- Каталог подкастов, результаты поиска подкастов и выпусков, переходы к поиску сказок и аудиокниг.
- Установка из HACS, архив релиза и сетевой установщик с резервной копией интеграции.

## 0.2.0

- Интерфейс по структуре Music Assistant с плеером и Яндекс-колонками сверху.
- Раздельный контекст управления колонками, выбор получателей, адаптация под телефон.
- Подборки Яндекса из API с динамическими названиями, обложками и содержимым.

## 0.1.2

- Исправлены адреса API, изоляция стилей и размер панели.
