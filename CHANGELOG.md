# Изменения

## 0.4.3

- Убрано строгое требование `yandex-music==3.2.0`: поддерживается `>=3.2.2,<4.0`, включая установленную у Music Browser версию 3.2.2.
- Добавлен порядок загрузки после Music Browser и YandexStation, чтобы установка общей библиотеки завершалась до импорта ЯМ-ХАОС.
- В CI добавлена проверка реальной библиотеки и необходимых методов в отдельном процессе, без подмен API и без авторизации.

## 0.4.2

- Добавлены сердечки «Мне нравится» в плеере и рядом с каждым треком, включая прямой внешний source.
- Повторное нажатие снимает отметку; состояние отображается везде и меняется после подтверждения API. Нажатие сердечка не запускает музыку.
- Состояние отметок читается по полному списку ID без ограничения отображаемой коллекции в 500 треков.
- Защищены повторные клики, смена текущей песни во время запроса и запоздалые ответы чтения.

## 0.4.1

- Прогресс прямого source рассчитывается по позиции и времени обновления получателя и обновляется каждую секунду, даже когда Cast сообщает только начальную отметку. При паузе счётчик останавливается.
- Финальная сборка прямого внешнего source имеет отдельный номер после тестовой 0.4.0: обновлены manifest, версия панели и URL модуля для обновления через HACS и браузер.
- Включены проверки защиты переключения, фактического прогресса получателя и продолжения Rotor Session.

## 0.4.0

- Добавлен явно включаемый прямой внешний source. Штатное воспроизведение Станций сохранено.
- Внешние плейлисты и «Моя волна» следуют состоянию получателя; завершение на Станции не прерывает поток.
- Прогресс, громкость, пауза и перемотка в прямом режиме относятся к внешнему устройству.
- Занятый получатель не перехватывается; два контроллера не могут назначить один прямой source разным Станциям.
- Исправлен разбор следующей партии Rotor Session: существующий session_id сохраняется, поскольку API не возвращает его повторно.

## 0.3.6

- «Региональные», «Темп», «Миксы» и «Исполнители» расположены в конце каталога «Моей волны», после жанров.
- «Спортивная музыка» перенесена в «Темп»; пустая группа «Другие жанры» больше не создаётся.
- «Узбекская народная музыка», которую API возвращает среди редакционных подборок, перенесена в «Этническую музыку».

## 0.3.5

- Из «Моей волны» убран «Фрагмент рекомендаций» и лишний запрос начального пакета треков.
- Национальные и региональные жанры объединены в «Этническую музыку» без ограничения числа направлений.
- Жанровые категории остаются цельными: вместо «Рок · 2» используются вложенные смысловые группы поджанров.
- Поиск в «Моей волне» фильтрует жанры, поджанры и тематические волны, раскрывает совпадения и восстанавливает раскрытые группы после очистки.
- Кнопки направлений переносятся в компактной сетке; длинные названия читаются и на телефоне.
- Категория «Блюз» получила собственную подпись; буги-вуги перенесено в танцевальную музыку.

## 0.3.4

- Жанры сгруппированы по родительским направлениям: рок, поп, фолк, метал, электроника и другие.
- На мобильном экране кнопки «Волна по треку» и «Волна по жанру» показывают текст под регулятором громкости.

## 0.3.3

- «Моя волна» переведена на Rotor Session API: `radio_session_id`, session queue, session feedback и продолжение без возврата к первому пакету.
- Добавлен каталог станций из API: волны по настроению, занятию, жанру, эпохе, языку и региону.
- Добавлены seeds текущего трека: волна по треку и волна по жанру.
- Технические seed-имена скрыты; станции сгруппированы в компактные горизонтальные ряды.
- Кнопки «Волна по треку» и «Волна по жанру» перенесены под регулятор громкости.
- Резервные копии установщика вынесены из `custom_components`, чтобы HA не сканировал их как интеграции.

## 0.3.2

- Волна под управлением HA по схеме Lampa: продолжение через Rotor cursor, batch и feedback; отдельная очередь каждой колонки.
- Настроения из API и волна по текущему треку. Продолжение работает без открытой страницы, пока работает HA.
- Выбор колонки одним тапом: обновления HA сохраняют кнопки и не переставляют нажатую карточку.
- Длинный ползунок громкости без повторения имени станции, увеличенный бегунок.
- На телефоне: сведения о треке, затем все кнопки управления со «Стоп», затем прогресс, громкость и дополнительные действия.

## 0.3.1

- Исправлена ошибка главной и «Мне нравится» для аккаунта с пустой коллекцией треков.
- Высота панели заполняет оставшееся окно даже при контейнере HA без заданной высоты.
- Отдельный раздел «Аудиокниги»: книги из коллекции и каталога, поиск по книгам, главы и загрузка следующих страниц.
- Обзор всех 163 методов библиотеки и результатов чтения API в `docs/api-capabilities.md`.

## 0.3.0

- Отдельная страница глобального поиска; фильтрация внутри разделов.
- Крупная кнопка выбора нативного `source` колонки, включая настроенные внешние плееры.
- Общая прокрутка рабочей области колесом мыши с закреплённым плеером.
- Каталог подкастов, результаты поиска подкастов и выпусков, переходы к поиску сказок и аудиокниг.
- Установка из HACS, архив релиза и сетевой установщик с резервной копией интеграции.

## 0.2.0

- Интерфейс по структуре Music Assistant с плеером и Яндекс-колонками сверху.
- Раздельный контекст управления колонками, выбор получателей, адаптация под телефон.
- Подборки Яндекса из API с динамическими названиями, обложками и содержимым.

## 0.1.2

- Исправлены адреса API, изоляция стилей и размер панели.
