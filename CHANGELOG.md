# Изменения

## 0.3.1

- Исправлена ошибка главной и «Мне нравится» для аккаунта с пустой коллекцией треков.
- Высота панели заполняет оставшееся окно даже при контейнере HA без заданной высоты.
- Отдельный раздел «Аудиокниги»: книги из коллекции и каталога, поиск по книгам, главы и загрузка следующих страниц.
- Обзор всех 163 методов библиотеки и результатов чтения API в `docs/api-capabilities.md`.

## 0.3.0

- Отдельная страница глобального поиска; фильтрация внутри разделов.
- Крупная кнопка выбора нативного `source` колонки, включая настроенные внешние плееры.
- Общая прокрутка рабочей области колесом мыши с закреплённым плеером.
- Каталог подкастов, результаты поиска подкастов и выпусков, переходы к поиску сказок и аудиокниг.
- Установка из HACS, архив релиза и сетевой установщик с резервной копией интеграции.

## 0.2.0

- Интерфейс по структуре Music Assistant с плеером и Яндекс-колонками сверху.
- Раздельный контекст управления колонками, выбор получателей, адаптация под телефон.
- Подборки Яндекса из API с динамическими названиями, обложками и содержимым.

## 0.1.2

- Исправлены адреса API, изоляция стилей и размер панели.
