# Разработка и проверки

Рабочая интеграция находится в `custom_components/yandex_music_chaos/`.
Backend использует библиотеку `yandex-music`, панель — браузерный custom element
в `www/panel.js`. Отдельная сборка frontend не требуется.

## Проверки

```sh
python -m unittest discover -s tests -v
node --check custom_components/yandex_music_chaos/www/panel.js
npm install --no-save playwright
npx playwright install chromium
node tests/panel.browser.mjs
python scripts/build_release.py
```

Unit tests используют подмены HA/API. Chromium проверяет навигацию, поиск,
очереди, адресатов команд, одно нажатие на колонку, четыре размера экрана и touch.
Архив интеграции и `SHA256SUMS` появляются в `dist/`.
Эти проверки также выполняются в GitHub Actions.

## Проверка с данными установленного HA

Задайте адрес Home Assistant в `YM_HA_URL`, SSH-алиас в `YM_HA_SSH` и запустите:

```sh
node tests/panel.browser.mjs --live
```

На HA требуется Advanced SSH & Web Terminal с доступом к Supervisor API.
Его служебный токен остаётся на HA. GET-запросы читают данные установленной
интеграции; команды воспроизведения, громкости и источников подменяются.
Проверка реального звука выполняется отдельно.

Скриншоты обычных тестов записываются в игнорируемый каталог `artifacts/`.

## Скриншоты для документации

```sh
node tests/panel.browser.mjs --live --docs
```

После проверок `scripts/capture_docs.mjs` создаёт отдельную страницу настоящей
панели с демонстрационным аккаунтом, колонками и состоянием плеера. Подборки
и каталог волн читаются из API. Личные плейлисты, логин, имена устройств и
состояние домашнего воспроизведения в изображения не попадают.

Изображения сохраняются в `docs/screenshots/`. Перед публикацией просмотрите
каждое изображение и проверьте читаемость подписей на телефоне.

## Выпуск

Версия должна совпадать в manifest, панели, URL модуля HA, установщике,
инструкциях README и браузерном тесте. Запишите изменения в `CHANGELOG.md`.
Соберите архив, сохраните его вместе с контрольной суммой в `release/<version>/`
и опубликуйте одинаковые коммит и тег в GitHub и GitVerse.

Не добавляйте в репозиторий токены, `.storage`, дампы аккаунта, личные
диагностические отчёты и конфигурацию домашних устройств.
