## ЯМ-ХАОС 0.3.2

- Поток волны под управлением интеграции: Rotor cursor, batch, start/finish/skip feedback и подгрузка следующих пакетов по схеме Lampa.
- Независимые очереди колонок в HA, продолжение после закрытия страницы, волна по текущему треку.
- Настроения из API; сохранение языка и характера подборки. Настройка настроения общая для музыкального аккаунта.
- Выбор колонки одним тапом, устойчивый к обновлению состояния HA во время нажатия.
- Увеличенный ползунок громкости без имени станции; мобильный плеер со строкой сведений о треке, отдельными рядами транспорта, прогресса и громкости. «Стоп» остаётся рядом с другими транспортными кнопками.

Проверка: 20 unit tests, браузерные проверки клика/тача, API маршрутов фронтенда и четырёх размеров экрана, сборка архива. Модель колонки проверяет 13 последовательных запусков, отдельные очереди, feedback, паузу/стоп, внешнее управление, ошибки и ограниченные повторы.

0.3.2 установлена на домашнем HA 2026.11.0 с резервной копией. Проверка конфигурации и перезапуск прошли; status/players и настройки волны отвечают, пять настроений получены из реального API. Браузерная проверка реально выдаваемого модуля с 19 запросами чтения, тремя колонками и четырьмя размерами экрана прошла без JS ошибок; команды воспроизведения в браузерном тесте подменены.

Физическое воспроизведение длинной волны, одновременная работа нескольких реальных колонок и передача звука с сохранением позиции этими проверками не подтверждены. Нужна локальная обратная связь Yandex Station. Сеансы не восстанавливаются после перезапуска HA. Это не синхронный мультирум.
