## ЯМ-ХАОС 0.3.4

- Жанры Rotor сгруппированы по родительским направлениям, чтобы каталог из 528 жанров не превращался в длинную сетку.
- Лестница жанров ограничивает каждый горизонтальный ряд 30 элементами; большие направления разбиваются на продолжения «Рок · 2», «Метал · 3» и т.д.
- Seed-идентификаторы скрыты; категории и подгруппы раскрываются компактными горизонтальными рядами.
- На мобильном экране под громкостью видны подписи «Волна по треку» и «Волна по жанру».

Проверка: 22 unit tests, browser tests на четырёх размерах и touch, node syntax check. Обновление основано на данных Rotor каталога домашнего аккаунта.
