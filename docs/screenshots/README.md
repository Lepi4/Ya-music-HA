# Скриншоты панели 0.3.6

| Файл | Содержание |
| --- | --- |
| `home-desktop.png` | Главная, выбор Станции, плеер и подборки API. |
| `wave-desktop.png` | Поиск по жанрам и вложенным поджанрам. |
| `wave-categories-desktop.png` | Последние жанры и порядок завершающих категорий. |
| `player-mobile.png` | Плеер и главная на экране шириной 390 px. |
| `wave-mobile.png` | Поиск народной музыки на телефоне. |

Это отрисовка настоящей панели: подборки и каталог получены из API, аккаунт,
имена колонок и состояние воспроизведения заменены демонстрационными данными.
Личные плейлисты и домашние адреса не используются.

Пересоздание: `node tests/panel.browser.mjs --live --docs`.
Настройка окружения описана в [CONTRIBUTING.md](../../CONTRIBUTING.md).
Музыка, обложки и товарные знаки принадлежат их правообладателям.
